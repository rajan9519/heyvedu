Good to know

Questions, answered.

Is HeyVedu really free?

Yes. HeyVedu is free and open source under the GNU GPLv3. There is no HeyVedu account or subscription.

Does it work without internet?

Yes, after the initial build and model downloads. The default speech recognition and cleanup pipeline runs entirely on your Mac. Optional Claude Code and Codex CLI cleanup modes require their corresponding online provider.

Does my audio leave my Mac?

No. Recorded audio stays in memory, is never written to disk, and is transcribed on-device—even if you choose an optional advanced cleanup engine.

Does HeyVedu save a dictation history?

No. HeyVedu does not store a dictation history. Debug builds log timing and errors, but not audio, transcripts, vocabulary, or typed keys.

Why does it need Accessibility permission?

Accessibility access lets HeyVedu observe the Control + Option push-to-talk shortcut and paste the finished text at your current cursor.

Which Macs are supported?

HeyVedu requires an Apple-silicon Mac running macOS 26.4 or later. Dictation is currently English-only.

How do I install it?

Clone or download the GitHub repository, then run ./scripts/run.sh. You’ll need Xcode with the macOS 26.4 SDK. There is no signed binary release yet.

What are advanced cleanup engines?

They are optional cleanup modes that use your locally installed and authenticated Claude Code or Codex CLI. Transcript text and configured vocabulary may be sent to Anthropic or OpenAI through your existing account; audio stays local.
